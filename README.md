# Web CV

A simple web-based CV built with [Vite](https://vitejs.dev/) and TypeScript.

## 🔧 Installation

Clone the repo and install dependencies:

```bash
git clone https://github.com/your-username/your-cv-repo.git
cd your-cv-repo
npm install
````

## 🚀 Start the project

Run the development server:

```bash
npm run dev
```

Your CV will be available at the address shown in the terminal (usually `http://localhost:5173`).

## 📄 About

This project renders a personal CV as a static website. Feel free to fork it, customize it, or use it as a template for your own.
